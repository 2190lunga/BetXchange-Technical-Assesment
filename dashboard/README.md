# Dashboard Assets

This folder contains the reporting design and business-facing dashboard planning for the BetXchange assessment.

## Current deliverable
- [../docs/powerbi-dashboard-blueprint.md](../docs/powerbi-dashboard-blueprint.md)

## Purpose
The dashboard should convert the validated KPI tables into a stakeholder-ready Power BI experience covering:

- executive performance
- customer retention
- financial risk
- product performance
- growth opportunities

## Planned outputs
- executive overview page
- customer retention page
- product analysis page
- risk and financial page
- growth and campaign page

## Reporting principle
The Power BI solution should prioritise business readability, traceable KPI logic, and clear stakeholder interpretation over technical complexity.
