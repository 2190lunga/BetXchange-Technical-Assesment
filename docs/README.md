# Documentation

This folder is intended for project documentation, project notes, methodology, and stakeholder-facing explanations.

## Purpose

- capture the business context,
- explain data definitions,
- document the analytics approach,
- record data quality findings,
- and support interview presentation.

## Typical Files

- project-overview.md
- data-dictionary.md
- data-quality-notes.md
- architecture-notes.md
- dashboard-specification.md
- [assumptions.md](./assumptions.md) -- methodology, sign conventions, known limitations, and every judgment call made, with evidence
- [ai-prompts-appendix.md](./ai-prompts-appendix.md) -- record of AI assistance used on this project, as required by the case study brief

## Standard

Documentation should stay short, clear, and business-readable so that technical and non-technical stakeholders can both understand the solution.
